```markdown
# Cybersecurity Audit Report Template

Use this template to produce a structured, professional audit report. Replace bracketed sections and redact sensitive details before publishing.

1. Title
- Audit title
- Target: [hostname / application / asset group]
- Date of assessment
- Author(s)

2. Executive Summary
- High-level findings
- Overall risk posture and business impact
- Key recommended actions for stakeholders

3. Scope
- In-scope assets (IP ranges, URLs, repos, APIs)
- Out-of-scope assets
- Test dates
- Authorization statement (attach signed permission)

4. Methodology
- Assessment types (reconnaissance, automated scans, manual testing, code review)
- Tools and versions
- Constraints and limitations

5. Asset Inventory
- Asset, role, criticality, owner/contact

6. Findings (for each)
- ID, Title, Severity (CVSS v3.x if used)
- Affected assets
- Summary
- Technical details and reproduction steps (redacted)
- Evidence (sanitized)
- Impact and likelihood
- Remediation steps
- References

7. Risk Matrix
- Counts by severity and suggested timelines

8. Remediation Verification
- How to verify fixes (automated checks or retest steps)

9. Recommendations & Roadmap
- Short-term (urgent)
- Medium-term
- Long-term

10. Appendix
- Tool list and versions
- Commands and scripts (sanitized)
- Glossary
```
